# Case Study 与解释验证实验设计

创建：2026-09-17。配套：[论文思路与大纲](ICLR2027_论文思路与大纲.md) 5.7 节、[实验依据与补实验计划](实验依据与补实验计划.md) P0「证据依赖」与 P1「解释验证」。

本设计对应正文 5.7 Case Study and Failure Analysis 与 Figure 3。它不是一节配图，而是把大纲 Limitations 里已经写明的两笔欠账做完：

- 「支持矩阵是模型响应，在删除高支持 Prior 的干预完成前不宣称解释具有因果忠实性」→ C1。
- 「共同支持是近似信号，不能直接证明历史论文已经覆盖目标中的该组合」→ C2。

另外补上失效侧的定位（C3）和正文两个真实案例（C4）。

## 0. 统一前提

所有实验使用**同一个冻结 checkpoint**，即 Panel A/C 那一个：

```text
results/runs/score_head_mixed_relabeled/residual_egrd/
  seed 173，residual 阶段 epoch 5/8，选模指标 novelty_selection_score_constrained
```

该目录目前在服务器上，本地 `results/runs/` 没有。开工前第一件事是确认它可加载、且重跑推理能复现 `metrics.json` 里的 All 行（0.7830 dev / Panel C 的 test 数字）。复现不了就停下，不要在一个对不上的 checkpoint 上做解释实验。

评测集：mixed 语料 test 划分 3,816 条，其中有域标签的 3,177 条。C1/C2 的干预实验按下面各自的抽样规则取子集，子集划定规则先写死再跑。

三条硬约束：

- 标签是模型生成的。本节任何结论只能说「模型的归因在干预下是否自洽/可定位」，**不能说「模型找到了真正新颖的部分」**。
- 不使用 `graph_form` / `mechanism_family` 这两个 facet 做任何分组或筛选，它们不可靠。
- 干预时文本、Pair 分数、排序、Joint 预测、全局特征必须**同步重算**。只换文本、留着原来的数值证据，只能叫局部通道干预，不能当证据干预报告。

## C0. 导出完整解释产物（其余三项的前置）

## C1. 支持矩阵的忠实性：定向删除高支持 Prior

**要回答的问题**：a_km 高，是不是真的意味着「模型对单元 m 的覆盖判断依赖于 prior k」？还是只要删掉任何一篇证据，所有单元的覆盖都会一起掉？

只做前者、不做后者的对照，实验说明不了任何事——这是这一项的全部要害。

### 抽样

从 test 里按 gold 四档分层抽 **500 条**（每档 125），要求该条至少有 4 篇有效 prior，且至少有一个单元满足 `coverage_score ≥ 0.5 且 active_probability ≥ 0.5`（有可解释的覆盖才谈得上删除）。抽样种子和结果 id 列表写进 `results/casestudy/c1/sample_ids.json`，跑之前提交。

对每条选定**目标单元** m\* = 在活跃单元中 coverage 最高者；**目标 prior** k\* = argmax_k a_{k,m\*}。

### 四个臂

| 臂 | 操作 | 控制的是什么 |
|---|---|---|
| A0 | 原始证据 | 基线 |
| A1 | 删除 k\* | 定向删除 |
| A2 | 删除一篇 pair coverage 分数与 k\* 最接近、但 a_{k,m\*} 低的 prior | 「删掉的是一篇强相关文献」这个解释 |
| A3 | 把 k\* 替换为一篇时间合法、来自其他 target 的随机 prior | `num_valid_priors_fraction` 变化这个解释（等预算） |

A1 与 A2 的差别是主结果，A3 用来确认 A1 的效应不是证据数量掉了一格造成的。A2 必须按 pair 分数做**配对匹配**，不能随机删一篇——随机删掉的往往是弱证据，那样 A1 赢得毫无意义。

每个臂都要走完整链路重算：

```text
删/换 prior → predict_pair_coverage.py → rank_priors_from_pair_predictions.py
            → joint coverage MIL 推理 → EGRD eval-only（--dump-explanation）
```

500 条 × 4 臂 ≈ 2,000 次 EGRD 前向 + 约 12,000 条 pair 打分，单卡数小时量级，不需要训练。

### 指标（预先定死）

1. **定向效应** Δc_{m\*} = c_{m\*}(A0) − c_{m\*}(A1)，报均值与配对 bootstrap 区间。
2. **定位比**（核心指标）

   ```text
   L = Δc_{m*} / mean_{m≠m*, 活跃} Δc_m
   ```

   支持矩阵若忠实，删 k\* 应当**主要打在 m\* 上**，L 显著大于 1。L≈1 说明矩阵只是在表达「证据总量」，那就按实际结果写，不要改指标。
3. **对照差** Δc_{m\*}(A1) − Δc_{m\*}(A2)，配对 bootstrap 4,000 次。
4. **等级变化** A1 相对 A0 新颖度等级上升 ≥1 的比例，按 gold 档分开报。
5. **单调性反例率**：删除证据后等级反而下降的比例。这个数必须报——大纲里已经写了「删除/加入证据后的整体新颖性方向并非无条件单调」，实测有多少反例是有信息的。

### 能写什么 / 不能写什么

L 显著 >1 且 A1−A2 区间不跨零 → 可以写「支持矩阵在干预下具有定位一致性」。**仍不能写因果忠实**，因为删除同时改变了编码输入的全部上下文。这一句写进 Limitations，不要省。

## C2. 交互残差：共同支持到底等不等于覆盖了组合

b_ij = max_k a_ki·a_kj 是「同一篇 prior 同时支持两个单元」的近似。它的风险是：一篇同时与两个单元都相关的 prior，未必覆盖了二者的**结合方式**。分三步验。

### C2a 观察性（先做，最便宜）

在 base dump 上，比较 gold `residual_type` 为组合类（`nontrivial_combination` 等）与非组合类两组的 max interaction residual 分布，报 AUC 与分布图。

**预期它不会很高**——历史记录里 `nontrivial_combination` 的 F1 只有 0.2396。这一项跑出弱信号就如实报弱信号，它是 C2b 的动机，不是卖点。

### C2b 构造性干预（这一项价值最高）

用语料自己构造两种证据集合，做**受控对照**：

- 取一条 target，其两个最活跃单元记为 A、B。
- 条件 (i)：证据里含一篇对 A、B 支持都强的 prior（a_kA、a_kB 均高）。
- 条件 (ii)：把那一篇换成**两篇**，一篇只支持 A、一篇只支持 B，且使 c_A、c_B 与条件 (i) 尽可能持平。

匹配靠 `dataset/mixed_relabeled_v1/idea_pair_coverage_llm.jsonl` 里的 pair 级 coverage 标签和分数来筛，目标是让两个条件下**单元覆盖相当、只有共同支持不同**。

预测：若 b_ij 表达的是模型所声称的东西，则 (i) 的 b_AB 明显高于 (ii)，而 c_A、c_B 在两条件下无显著差异；随之 r_AB 在 (ii) 更高。

报：能构造出匹配对的数量、b_AB 与 c_A/c_B 的条件差、交互残差差、以及最终等级差。**这是唯一能把「共同支持 ≈ 覆盖了组合」这句话从近似说明变成可测结论的实验**。匹配不上足够多的对（<50 对）就降级为定性观察，别硬凑。

### C2c 人工核验（30 条）

在 b_ij 高的组合案例里抽 30 条，两名标注者只看 target 文本与那篇 prior 原文，回答：这篇 prior 是否真的覆盖了 target 里这两个成分的**结合**？记一致率与 κ。标注者不看模型预测。

结论写法：「在 N 条高共同支持案例中，人工判断 x/N 确实覆盖了组合关系」——这是一个可以直接写进 Limitations 支撑句的数字，无论 x 大小。

## C3. 失效解剖：high → moderate 到底丢在哪一段

已知这是主要失效模式（约一半错误是 high→moderate），且阈值方向已经排除过三次。所以这一节不要再做阈值，而是**沿管线定位**。

对所有 gold=high、pred=moderate 的样本，按预先定义的规则归因到四个位置之一：

| 位置 | 判定规则（用 base dump 字段） |
|---|---|
| 上游覆盖高估 | `joint_evidence_score` − `gold_joint_coverage_score` 超过正确 high 组的 75 分位 |
| 单元残差不足 | max `semantic_unit_residual_scores` 低于正确 high 组的 25 分位 |
| 交互残差近零 | max `interaction_residual_scores` 低于正确 high 组的 25 分位 |
| 融合/证据头塌缩 | `pred_novelty_fusion_gates.residual` 低于正确 high 组 25 分位，或 `pred_evidence_sufficiency` 落在中位数窄带内 |

规则先写死再算，允许一条样本命中多个位置，报联合分布而不是强行单选。

配一个**上界干预**：`--use-gold-joint-evidence` 这个开关已经存在（[:4201](../../model/novelty_pipeline/train_residual_egrd.py#L4201)）。用它重跑一次，看 high→moderate 错误被回收了多少。

- 回收比例高 → 瓶颈在上游 Joint Coverage，正文就这么写，这是干净的归因。
- 回收比例低 → 瓶颈在 EGRD 内部，那么单元/交互残差的表达力就是真问题，同样照写。

这个开关是 oracle 诊断，结果只能进失效分析，**不能进任何主表**。

## C4. 正文的两个真实案例

大纲里写了「正文最终应使用经核验的真实案例」。选例规则预先登记，并在正文写出候选池大小：

正例需同时满足四条：

1. 预测正确且 gold = high；
2. 单元 top token 的人工核验为「连贯」（见下）；
3. 在 C1 里表现出定位效应（该条的 L > 中位数）；
4. 是 C2c 中人工确认的组合案例。

负例取 C3 中归因明确的一条 high→moderate。

正文写「在 N 条候选中有 n 条同时满足四条筛选条件，图中展示其一」，把 N 和 n 都写出来。**不写出候选池就是隐性挑样本**，这是这一节最容易被审稿人抓住的地方。

Figure 3 建议布局：左 = K×M 支持矩阵热力图（行标 prior 位次，列标单元，单元下方挂 top token）；中 = 单元覆盖 c_m 与残差 r_m 并排条形；右 = 删除 k\* 后的同一张矩阵与等级变化。三联图把 C1 的结论直接画在案例上，比单独一张热力图强得多。

### 单元-文本对齐的人工核验

30 条 × 8 单元。给标注者 target 原文和某单元的 top-8 token，问：这些 token 是否对应文本中一个连贯的单一成分（是/部分/否）。报「连贯」比例与两标注者 κ。

这是唯一能支撑「语义单元是可读的」这一说法的证据。跑之前不要在正文写「单元对应可解释的语义成分」。

| 项 | 依赖 | 新代码 | 计算 | 不做的后果 |
|---|---|---|---|---|
| C0 | — | ~20 行 | 一次推理 | 后面全都做不了 |
| C1 | C0 | 一个干预脚本（~250 行，串已有四个阶段脚本） | 2,000 次前向 | Limitations 里那笔欠账留着，Figure 3 只是模型响应的可视化 |
| C3 | C0 | ~150 行分析脚本 | 一次 oracle 重跑 | 主要失效模式仍然只有现象没有定位 |
| C2b | C0 | ~200 行构造 + 复用 C1 的干预链路 | 数百次前向 | 贡献 3 的交互项停留在近似说明 |
| C4 | C1/C2/C3 | 画图 | — | 正文只能用 A/B 示意图 |
| C2c + 对齐核验 | C0 | 标注表 | 人工 | 「可读」「覆盖了组合」两句话没有证据 |

**必做**：C0 → C1 → C3。这两项是已经在论文里写下承诺的部分。
**强烈建议**：C2b，它的性价比最高，而且是目前唯一能正面支撑交互残差设计的实验。
**有人力再做**：C2c 与对齐核验；没做就不要在正文出现对应措辞。

## 这一节能得出的结论范围

做完 C0–C4，5.7 节可以支持的表述是：

- 模型对单元覆盖的归因在定向证据删除下表现出定位性（C1，附带非因果声明）。
- 交互残差在受控证据构造下确实区分「一篇覆盖两者」与「两篇各覆盖其一」（C2b，或者如实报告它区分不了）。
- 主要失效模式可定位到管线的具体一段，并给出 oracle 上界（C3）。
- 正文案例来自登记的筛选规则，候选池规模公开（C4）。

不能支持、也不要写的：解释具有因果忠实性；模型识别出了真正的创新点；共同支持等价于组合覆盖；语义单元对应预先命名的固定槽位。
